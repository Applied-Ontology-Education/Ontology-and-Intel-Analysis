# Using GitHub Discussions

GitHub Discussions is the primary asynchronous discussion space for this course.

Course Discussions:

https://github.com/Applied-Ontology-Education/Ontology-and-Intel-Analysis/discussions

## Recommended Discussion Categories

- **Announcements**
- **Undergraduate Discussion Questions**
- **Graduate Presentations**
- **Course Questions**
- **Project Help**

## Graduate Presentations

Graduate students should post links to presentations in the **Graduate Presentations** category for each presentation window.

A presentation post should contain:

```markdown
## Student
Name or GitHub username

## Presentation
Presentation 1 or Presentation 2

## Title
Presentation title

## Design Pattern
Brief description of the intelligence-analysis problem or pattern.

## Recording
Link

## Supporting Materials
Links, if applicable
```

## Course Questions and Project Help

Before opening a new question:

1. Check whether the question has already been answered.
2. Identify the relevant week or assignment.
3. Use a descriptive title.
4. Include enough context for others to understand the question.

Do not post classified, controlled, proprietary, operational, personal, or otherwise sensitive information in Discussions.
