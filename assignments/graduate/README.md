# Graduate Track

The graduate track uses the shared readings and lectures in the main course schedule but has its own assessment sequence.

## Assessment

| Assessment | Weight |
|---|---:|
| Presentation 1 | 20% |
| Presentation 2 | 30% |
| Final Project | 50% |

## Presentations

Graduate students complete two asynchronous recorded presentations.

Both presentations should center on an **ontology design pattern addressing some aspect of intelligence analysis**.

Students are encouraged to develop the same pattern across both presentations so that Presentation 2 represents a substantial improvement on Presentation 1.

See the complete [Graduate Presentation instructions](presentations.md).

## Final Project

The [Final Project](../final-project.md) is an ontology development project focused on an intelligence-analysis problem, domain, or workflow.

Graduate students work under the same core Final Project specification as undergraduate students but are expected to demonstrate greater conceptual and technical depth.

The strongest trajectory is:

```text
Design Pattern
      ↓
Presentation 1
      ↓
Feedback and Revision
      ↓
Presentation 2
      ↓
Ontology Implementation and Evaluation
      ↓
Final Project
```

## Graduate-Level Expectations

Graduate work should demonstrate greater rigor, justification, and depth rather than merely a larger ontology.

Strong graduate projects will normally demonstrate several of the following:

- substantial reuse or alignment with existing ontology content;
- deeper engagement with relevant scholarly literature;
- explicit and well-justified formal axioms;
- use of automated reasoning where appropriate;
- systematic evaluation against competency questions;
- comparison of plausible alternative modeling approaches;
- a reusable ontology design pattern;
- clear treatment of difficult conceptual distinctions; or
- documentation suitable for contribution to an open-source ontology project.
